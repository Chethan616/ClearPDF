# ClearPDF

ClearPDF is an open-source PDF reader for Android with a modern liquid glass style interface. It focuses on smooth performance, minimal design, and a clean reading experience.

---

## Features

* Liquid glass inspired UI with transparency and blur effects
* Fast and lightweight PDF rendering
* Simple and distraction-free reading interface
* Built using Jetpack Compose
* Open source and customizable

## Getting Started

```bash
git clone https://github.com/Chethan616/ClearPDF.git
```

1. Open the project in Android Studio
2. Sync Gradle
3. Run on a device or emulator
